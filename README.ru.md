Веб-приложение для лизинговой компании: клиенты, каталог техники, договоры лизинга, калькулятор платежей и панель статистики. Курсовая работа.

Бэкенд — REST API на Go (Gin + GORM + PostgreSQL). Фронтенд — одностраничное приложение на чистом JavaScript, его отдаёт тот же сервер.

## Возможности

- **Авторизация** — регистрация и вход, JWT в заголовке `Authorization: Bearer`, пароли хешируются через bcrypt.
- **Три роли** — администратор, менеджер и клиент; права проверяются на каждом эндпоинте.
- **Клиенты** — карточки клиентов с реквизитами (ИНН, адрес, контакты).
- **Техника** — каталог предметов лизинга со стоимостью, статусом и привязкой к клиенту.
- **Договоры** — клиент подаёт заявку, менеджер её обрабатывает; статусы: `pending → in_processing → active → completed`. Ежемесячный платёж и общая сумма считаются автоматически.
- **Калькулятор лизинга** — открытый эндпоинт, аннуитетные или убывающие платежи, ставка зависит от категории техники.
- **Статистика** — панель для менеджеров и администраторов (графики на Chart.js).
- **Управление пользователями** — администратор создаёт, редактирует, одобряет и удаляет учётные записи.
- **Мягкое удаление** для всех сущностей.

## Роли

| Действие | Клиент | Менеджер | Администратор |
|---|:---:|:---:|:---:|
| Калькулятор, редактирование своего профиля | ✅ | ✅ | ✅ |
| Заявка на договор, просмотр своих договоров и техники | ✅ | ✅ | ✅ |
| Управление клиентами и техникой | — | ✅ | ✅ |
| Обработка договоров, смена статуса | — | ✅ | ✅ |
| Просмотр статистики | — | ✅ | ✅ |
| Управление пользователями | — | — | ✅ |

При самостоятельной регистрации всегда создаётся клиент. Учётные записи менеджеров и администраторов создаются сид-скриптом или администратором.

## Запуск

Понадобятся Go 1.25+ и PostgreSQL.

```bash
git clone https://github.com/dariaef675/leasing.git
cd leasing

# 1. Конфигурация
cp .env.example .env        # затем укажите свои DB_PASSWORD и JWT_SECRET

# 2. База данных
createdb -U postgres leasing_db

# 3. Запуск (таблицы создаются автоматически при старте)
go run main.go

# 4. По желанию: создать учётные записи администраторов и менеджеров
go run scripts/seed_users.go
```

Приложение откроется на <http://localhost:8082>.

## API

Базовый путь: `/api/v1`. Все эндпоинты, кроме открытых, требуют заголовок `Authorization: Bearer <token>`.

| Метод | Путь | Доступ | Описание |
|---|---|---|---|
| `POST` | `/register` | открытый | Регистрация клиента |
| `POST` | `/login` | открытый | Вход, возвращает JWT |
| `POST` | `/calculate-lease` | открытый | Расчёт ежемесячного платежа |
| `GET` `PUT` | `/profile` | любая роль | Просмотр и редактирование профиля |
| `GET` | `/stats` | менеджер, администратор | Статистика для панели |
| `GET` `POST` | `/clients` | менеджер, администратор | Список и создание клиентов |
| `GET` `PUT` `DELETE` | `/clients/:id` | менеджер, администратор | Просмотр, изменение, удаление клиента |
| `GET` | `/equipment`, `/equipment/:id` | любая роль | Клиент видит только свою технику |
| `POST` `PUT` `DELETE` | `/equipment`, `/equipment/:id` | менеджер, администратор | Управление техникой |
| `GET` `POST` | `/contracts`, `/contracts/:id` | любая роль | Клиент видит и создаёт только свои |
| `PUT` `DELETE` | `/contracts/:id` | менеджер, администратор | Обработка и удаление договоров |
| `GET` `POST` `PUT` `DELETE` | `/users`, `/users/:id` | администратор | Управление пользователями |

Для проверки работоспособности есть `GET /health`.

### Пример расчёта

```bash
curl -X POST http://localhost:8082/api/v1/calculate-lease \
  -H "Content-Type: application/json" \
  -d '{"asset_value": 3000000, "contract_term": 36, "category": "грузовой", "payment_type": "even"}'
```

```json
{ "monthly_payment": 102532.89 }
```

`payment_type` — `even` (аннуитетный) или `decreasing` (убывающий). Годовая ставка выбирается по категории:

| Категория | Ставка |
|---|---|
| `легковой` | 12% |
| `коммерческий` | 13% |
| `грузовой` | 14% |
| `спецтехника` | 15% |
| `сельхозтехника` | 16% |
| `оборудование` | 17% |

Аннуитетный платёж считается по формуле

```
A = P · r · (1 + r)^n / ((1 + r)^n − 1)
```

где `P` — стоимость предмета лизинга, `r` — месячная ставка, `n` — срок в месяцах.
