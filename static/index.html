Возможности системы

Лизинговый калькулятор

Главная фишка — удобный лизинговый калькулятор, который позволяет быстро рассчитать стоимость лизинга с учётом всех параметров: стоимости оборудования, срока договора и типа платежей.

Роли в системе

Клиент

  • • Просмотр доступного оборудования
  • • Использование лизингового калькулятора
  • • Подача заявок на лизинг
  • • Просмотр своих договоров
  • • Управление личным профилем

Менеджер

  • • Управление клиентами и их данными(обновление и удаление)
  • • Управление оборудованием(редактировние, удаление)
  • • Обработка заявок на лизинг(одобрение, обработка, редактирование, удаление)
  • • Управление договорами
  • • Просмотр статистики и аналитики

Администратор

  • • Полный доступ ко всем функциям системы
  • • Управление пользователями и ролями
  • • Одобрение регистраций
  • • Просмотр архивных договоров(только для админа)
  • • Системная статистика и отчёты
